# Client SSH — Premium Visual Skin

Zakres tej gałęzi obejmuje pełny graficzny system premium dla całej aplikacji, a nie zmianę samej palety kolorów.

- wektorowy splash screen renderowany bez utraty ostrości na ekranach Full HD i 4K,
- wspólne tło command center z głębią, siatką, światłem, krzywymi sieci i węzłami,
- półprzezroczyste powierzchnie i spójna hierarchia komponentów,
- premium nawigacja, profile, monitor, historia, ustawienia i dialogi,
- osobne dopracowane powierzchnie terminala oraz SFTP,
- brak zmian w logice SSH, host-key verification i obsłudze sekretów.

Gałąź jest testowa i pozostaje bez merge oraz release do czasu zatwierdzenia wyglądu i przejścia kompletnego CI.
