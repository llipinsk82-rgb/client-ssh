# Kryteria odbioru

1. Splash screen ma wyglądać jak pełnoprawna grafika premium i skalować się bez widocznej pikselizacji.
2. Premium wygląd ma obejmować wszystkie główne ekrany, terminal, SFTP oraz dialogi.
3. Nie może to być jedynie zamiana zieleni na niebieski — wymagane są nowe warstwy graficzne, głębia, światło, szkło i sieć.
4. Funkcjonalność SSH, Telnet, SFTP, host-key verification, Session Keeper i storage nie może zostać zmieniona.
5. Testy jednostkowe, kontrola sekretów i debug APK muszą przejść przed przekazaniem wersji do testu.
